### Package guides and API reference on the docs site

Package READMEs now link to the documentation website. Package setup, examples,
and platform limits live alongside the app guides. Each public package also has
an API reference generated from its exported declarations and TSDoc.

See the [UI package guide](https://octane-xplat.goddardai.org/package-ui) and
[UI API reference](https://octane-xplat.goddardai.org/api-ui).
