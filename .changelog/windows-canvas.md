### Draw with Canvas on Windows

`@octane-xplat/canvas` now uses a native drawing surface on the experimental Windows target. Use the same `Canvas` component for 2D, WebGL, WebGL2, and WebGPU. Check that the requested context is available before drawing.

See the [Canvas guide](https://octane-xplat.goddardai.org/packages/package-canvas) for a drawing example.
