### Measure text with Pretext across Xplat targets

Install `@octane-xplat/pretext` to use Pretext's paragraph and rich-inline layout APIs with text measurements from web, iOS, Android, macOS, Linux/GTK, and Windows. See the [Pretext guide](https://octane-xplat.goddardai.org/package-pretext) for setup, examples, and native font limits.
