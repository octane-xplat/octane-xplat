### Clip SmoothCorners content with a CSS class

A class that sets `overflow: hidden` on `SmoothCorners` now clips children to the curve, including classes generated by Bamboo or placed in a CSS layer. Previously the component’s default could override the class. Remove any `!important` workaround for this issue.

```css
@layer app {
  .clipped-image {
    overflow: hidden;
  }
}
```
