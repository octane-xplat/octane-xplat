# Recommended public API changes

A compact change list, ordered by impact on correct agent use. The [whole-package vision](package-vision.md) supplies target contracts for all 126 concepts, including those governed by the cross-cutting changes here. These are target contracts, not implementation instructions or currently supported APIs. D1–D6 in [approved decisions](approved-decisions.md) establish the direction; the concrete recommendations below use the reviewer’s authorized judgment. Exact names follow **Astryx → React Aria → React Native → generic frontend**, with equivalent semantics. Retain reference-backed names rather than automatically replacing them with generic names.

## First: remove misleading contracts

| API or boundary                                                                                                                                                                                                  | Recommended change                                                                                                                                                       | Why                                                                                   |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| [Root and conditioned exports](../../../packages/ui/src/index.macos.ts#L249), [CSS exports](../../../packages/ui/package.json#L90)                                                                                     | Give the shared import the same intended values and types on every target; make development and published paths agree. Move target-specific contracts to explicit paths. | An import that works locally must remain valid after publishing and changing targets. |
| [FocusScope](../../../packages/ui/src/props.ts#L6789), [focus hooks](../../../packages/ui/src/use-focus.tsrx#L1), [useGridList](../../../packages/ui/src/props.ts#L6975), [Outline](../../../packages/ui/src/props.ts#L6637) | Implement accepted behavior or expose an explicit supported subset/capability. Separate DOM discovery from portable outline data.                                        | Successful typechecking currently conceals unsupported or different behavior.         |
| [iOS controls](../../../packages/ui/src/ios/index.ts#L7), [Android controls](../../../packages/ui/src/android/index.ts#L7)                                                                                             | Honor the field-state and accessibility props they accept, or narrow their public types.                                                                                 | Disabled and labeled controls must mean what their types promise.                     |
| [Button](../../../packages/ui/src/props.ts#L2744), [Progress / Meter](../../../packages/ui/src/props.ts#L1406)                                                                                                         | Expose action failures; give Meter the semantics and accessibility role of a meter.                                                                                      | Hidden failures and incorrect roles cause incorrect behavior despite plausible code.  |
| [Prop clearing](../../docs/architecture.md)                                                                                                                                                              | Removing an optional shared prop restores its documented default. Specify omitted, undefined, null, and explicit reset semantics per contract.                           | Editing JSX should describe the current UI without retained host values.              |

## Next: reduce choices and strengthen feedback

| API or boundary                                                                                                                                                                                                 | Recommended change                                                                                                                                                      | Why                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| [Imports](../../../packages/ui/package.json#L40)                                                                                                                                                                   | Keep general UI at the root; give routing, data, Markdown, and chat their canonical `/routing`, `/data`, `/markdown`, `/chat` entrypoints with related types and hooks. | Purpose boundaries make imports inferable without scattering ordinary UI.           |
| [Names](../../../packages/ui/src/props.ts#L6121), [public props](../../../packages/ui/src/props.ts#L318)                                                                                                              | Apply the naming hierarchy to each comparable contract; export matching props, events, item types, and handles. Remove public internal fields and unbounded `any`.      | Discoverable, precise declarations support completion and repair.                   |
| [Button](../../../packages/ui/src/props.ts#L2744), [state/events](../../../packages/ui/src/props.ts#L490), [menus](../../../packages/ui/src/props.ts#L2888)                                                              | Choose one spelling and behavior per state/action; remove overlapping disabled/loading/open aliases and competing action callbacks.                                     | Aliases and competing handlers leave precedence ambiguous.                          |
| [TextInput](../../../packages/ui/src/props.ts#L517), [boolean inputs](../../../packages/ui/src/props.ts#L1382), [choices](../../../packages/ui/src/props.ts#L2852), [overlays](../../../packages/ui/src/props.ts#L2071)     | Provide consistent controlled, initial, and change roles where supported; define controlled-plus-initial conflicts and callback payloads.                               | State ownership should transfer predictably between related components.             |
| [Selector](../../../packages/ui/src/props.ts#L3226), [menus](../../../packages/ui/src/props.ts#L2888), [disclosure](../../../packages/ui/src/props.ts#L2784)                                                             | Tie selection mode to its exact value and event type; distinguish action items, links, sections, and separators.                                                        | Invalid combinations should fail while code is being written.                       |
| [Date inputs](../../../packages/ui/src/props.ts#L602), [Calendar](../../../packages/ui/src/props.ts#L700), [NumberInput](../../../packages/ui/src/props.ts#L3181)                                                        | Establish empty/clear values per family; distinguish local dates, local date-times, and instants; replace contradictory picker flags with one strategy.                 | Empty and temporal values should not change meaning between consumers.              |
| [Time](../../../packages/ui/src/props.ts#L6440), [Stack](../../../packages/ui/src/props.ts#L120), [resizing](../../../packages/ui/src/props.ts#L5335), [query cache](../../../packages/ui/src/query-cache.ts#L55)           | Use explicit consistent units for timestamps, durations, layout, and tokens; remove magnitude-based timestamp guessing.                                                 | A number should have one meaning independent of the receiving API.                  |
| [Table](../../../packages/ui/src/props.ts#L3811), [VirtualList](../../../packages/ui/src/props.ts#L1116), [TreeList](../../../packages/ui/src/props.ts#L3858), [collection data](../../../packages/ui/src/list-data.ts#L12) | Preserve item generics; share stable key and selection contracts; distinguish keys from indices; expose controlled expansion where needed.                              | Data can move between stores and views without losing identity or type information. |
| [Routes](../../../packages/ui/src/props.ts#L2349), [route definitions](../../../packages/ui/src/props.ts#L2497), [PowerSearch](../../../packages/ui/src/props.ts#L5936), [Table](../../../packages/ui/src/props.ts#L3811)   | Infer route parameters, filter values/operators, and column keys from their defining schema through all consuming methods.                                              | Invented names and incompatible values become actionable type errors.               |

## Then: make composition and operations reliable

| API or boundary                                                                                                                                                                                                        | Recommended change                                                                                                                                                                    | Why                                                                                                  |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| [ComplexSelector](../../../packages/ui/src/props.ts#L3594), [Item / List](../../../packages/ui/src/props.ts#L3152), [Table](../../../packages/ui/src/props.ts#L3811)                                                            | Use named context fields for multi-argument render callbacks and consistent slot roles within related families.                                                                       | Agents can inspect available fields instead of memorizing positional conventions.                    |
| [Field](../../../packages/ui/src/props.ts#L490), [Tabs](../../../packages/ui/src/props.ts#L2323), [menus](../../../packages/ui/src/props.ts#L2888), [focus](../../../packages/ui/src/props.ts#L6789)                               | Make required providers/anatomy explicit; make label, description, error, keyboard, and focus relationships part of normal composition.                                               | Correct accessibility should follow the preferred structure with fewer manual connections.           |
| [Bottom sheets](../../../packages/ui/src/props.ts#L1954), [toasts](../../../packages/ui/src/props.ts#L1772), [windows](../../../packages/ui/src/props.ts#L2699), platform modals                                                | Return typed handles for the created instance, including relevant completion, close, and disposal operations; agree on shared window results and data behavior.                       | Concurrent resources need explicit ownership and observable outcomes.                                |
| [ScrollableArea](../../../packages/ui/src/props.ts#L1016), [VirtualList](../../../packages/ui/src/props.ts#L1116), [WebView](../../../packages/ui/src/props.ts#L1147), [refs](../../../packages/ui/src/ref-list.ts#L1)             | Export typed portable handles; bound raw host access; make ref composition preserve each consumer’s ref.                                                                              | Consumers should not guess host methods or lose an existing ref while composing props.               |
| [Stores](../../../packages/ui/src/store.ts#L16), [collection data](../../../packages/ui/src/list-data.ts#L12), [indicators](../../../packages/ui/src/props.ts#L7025)                                                            | Distinguish reactive reads from snapshots; expose readonly snapshots, separate value assignment from updater functions, and define selector equality.                                 | Mutations and subscriptions become visible rather than relying on hidden reactivity rules.           |
| [Async lists](../../../packages/ui/src/async-list.ts#L59), [query cache](../../../packages/ui/src/query-cache.ts#L55), [Button](../../../packages/ui/src/props.ts#L2744)                                                        | Expose completion, pending/error state, cancellation where supported, and pagination readiness; specify overlapping requests and retries.                                             | Agents can await, recover, and avoid repeating operations blindly.                                   |
| [WebView](../../../packages/ui/src/props.ts#L1147), [Markdown](../../../packages/ui/src/props.ts#L6678), [AppShell](../../../packages/ui/src/props.ts#L4852), [chat tool calls](../../../packages/ui/src/props.ts#L4123)           | Make alternative content sources and state-dependent configurations exclusive and precisely typed.                                                                                    | Permissive bags and independent optional fields hide incompatible choices.                           |
| [Theme](../../../packages/ui/src/theme/theme-scheme.ts#L5), [styled](../../../packages/ui/src/styled.web.tsrx#L5), [icons](../../../packages/ui/src/props.ts#L1434)                                                             | Distinguish preference from resolved appearance; type variants and icon identifiers; bound platform customization explicitly.                                                         | Styling decisions should be discoverable through the same public contract as components.             |
| Diagnostics, [route definitions](../../../packages/ui/src/props.ts#L2497)                                                                                                                                                 | Give runtime contract failures stable codes, field paths, expected shapes, and repair hints. Reject duplicate route names; report missing prerequisites.                              | Runtime feedback should identify the smallest correct edit.                                          |
| [Chat composer](../../../packages/ui/src/props.ts#L4303), [tokens](../../../packages/ui/src/props.ts#L4213), [messages](../../../packages/ui/src/props.ts#L4019), [scrolling](../../../packages/ui/src/props.ts#L4099)             | Make drafts serializable and tokens round-trip; separate send/cancel from draft state and sender/delivery from presentation; expose following-latest behavior.                        | Agents can preserve drafts and update messages without coordinating undocumented parallel state.     |
| [Markdown streaming](../../../packages/ui/src/index.shared.ts#L27), [syntax](../../../packages/ui/src/props.ts#L6226), [Outline](../../../packages/ui/src/props.ts#L6637)                                                       | Offer one streaming parser, readable document data, and typed code tokens/offsets at the Markdown entrypoint; keep tuning and segmentation plumbing private.                          | Consumers can render streamed content without assembling internal helper sequences.                  |
| [Search sources](../../../packages/ui/src/props.ts#L3285), [CommandPalette](../../../packages/ui/src/props.ts#L3757), [chat triggers](../../../packages/ui/src/props.ts#L4213)                                                  | Share request-scoped abortable search and distinguish query text, selected data, and executed commands.                                                                               | Sharing a source should not let one consumer cancel another consumer’s request.                      |
| [SafeArea](../../../packages/ui/src/props.ts#L1332), [keyboard avoidance](../../../packages/ui/src/props.ts#L1358), [measurement](../../../packages/ui/src/props.ts#L1895), [Grid](../../../packages/ui/src/props.ts#L106)         | Specify inset consumption, measurement coordinate space/readiness, and a bounded grid grammar with explicit numbering.                                                                | Layout values should mean the same thing without inspecting the active host.                         |
| [Keyboard](../../../packages/ui/src/use-keyboard.ts#L1), [gestures/animation](../../../packages/ui/src/props.ts#L11), [clipboard](../../../packages/ui/src/use-clipboard.ts#L1)                                                 | Publish normalized event domains, explicit units and attachments, and observable animation/copy outcomes.                                                                             | Interaction and sequencing need precise contracts beyond a generic event or host object.             |
| [iOS](../../../packages/ui/src/ios/index.ts#L11), [Android](../../../packages/ui/src/android/index.ts#L11), [NativeScript hosts](../../../packages/ui/src/nativescript/index.ts#L1), [web](../../../packages/ui/src/web/index.ts#L1)     | Give authentic widgets matching public types and shared value/identity contracts; separate host integration and DOM-specific APIs from portable UI.                                   | Platform choices stay explicit without competing aliases for unrelated contracts.                    |
| [Router](../../../packages/ui/src/props.ts#L2349), [query cache](../../../packages/ui/src/query-cache.ts#L55), [icon registry](../../../packages/ui/src/props.ts#L1434), [group defaults](../../../packages/ui/src/props.ts#L5491) | Make app/instance scope and child-over-parent precedence explicit; keep ordinary components usable without unrelated providers.                                                       | Local component changes should not depend on hidden global initialization or alter another consumer. |
| Public declarations and examples                                                                                                                                                                                       | Put imports, defaults, units, errors, prerequisites, and related APIs beside their declarations; show one preferred supported composition. Keep migration aliases clearly deprecated. | Agents need a reliable local answer rather than scattered conventions.                               |

The linked source declarations and leaves supply evidence for the current contracts. The whole-package vision supplies the complete destination map. The priorities are design judgments; no agent benchmark or runtime qualification of the proposed API has been performed. Breaking changes need migration guidance and reconciliation of supported docs, examples, and recipes when implemented.
