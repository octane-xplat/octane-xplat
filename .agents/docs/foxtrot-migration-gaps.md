# Foxtrot migration gaps

Foxtrot cannot retain its full editor behavior through Xplat's current native
editor facade. Prioritize a mobile host for the existing ProseMirror/Yjs engine,
then authentication/session integration. Local semantic search needs a separate
runtime decision. Ordinary UI, storage, and media mostly have existing homes.

Snapshot: 2026-10-04; Foxtrot `78a69f70`, octane-xplat `5021c99e`
(package manifests `0.10.0`), goddard-xplat `34d0c39` (consumes `^0.9.0`).
This is source analysis, not an iOS/Android runtime qualification. `exists`
means implemented in this checkout; it does not assert registry availability
or production readiness. `partial` means some required behavior is absent;
`missing` means no matching Xplat implementation was found.

## Ranked delta

permits a reduced experience. **Trivial** needs routine app adaptation, not a
new framework capability. Conditional blockers are explicitly marked.

## Architectural gates before implementation

| Gate                  | Recommended decision / acceptance evidence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Editor ownership      | Prefer a hosted DOM editor over rebuilding Foxtrot semantics on Aztec. Keep Y.Doc/EditorView/node views together; bridge structured commands/events and ready/dispose state. Demonstrate lossless nested `.fxt` reopen, concurrent edits, carets, undo, revocation, clipboard, IME, keyboard/selection and background resume on **both** phones. A whole-app WebView could retain more React code, but requires the full Coreframe host/session contract.                                                                                                            |
| Local inference       | Treat NativeScript compatibility as unproven. [Transformers.js documents ONNX-backed browser inference](https://huggingface.co/docs/transformers.js/index); this does not establish support in the native JS engine. Qualify exact model/tokenizer/revision, cold download/cancel, cache/offline reload, memory/latency, embedding compatibility and background interruption. Decide WebView versus native ONNX before estimating the port.                                                                                                                          |
| Passkey identity      | Browser `localhost` RP semantics cannot simply become a native credential ceremony. [Apple requires associated webcredentials domains](https://developer.apple.com/documentation/authenticationservices/connecting-to-a-service-with-passkeys); [Android requires Credential Manager and Digital Asset Links](https://developer.android.com/identity/passkeys/create-passkeys). Decide RP/origin/session migration, then test existing accounts, create/get/cancel, email/social callbacks and logout. Hosted auth requires an explicit secure app-session exchange. |
| Persistence ownership | Separate credentials/NaCl keys (secure storage), scoped query snapshots (bounded KV/files), and durable documents/media/indexes (files/SQLite). Preserve Foxtrot's interfaces and auth cache invalidation; verify reopen, account switch, logout, failed writes and cleanup. Do not count today's memory-only mobile workspace as durable parity.                                                                                                                                                                                                                    |
