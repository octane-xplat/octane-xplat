# Retired Linux WebKitGTK app host

The DOM-in-WebKitGTK app host, shared native-service RPC, and its macOS stand-in have been removed. Prior runtime checks apply only to the retired implementation and do not qualify the native GTK renderer. Use [native GTK setup](../../../docs/platform/linux-gtk.md) for current packaging and support boundaries. Embedded WebView widgets remain separate.
