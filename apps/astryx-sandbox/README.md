# @xplat/astryx-sandbox

An Octane Xplat replica of the upstream [Astryx](https://github.com/facebook/astryx)
sandbox (`apps/sandbox`), pinned at commit
`ebd939b665361a078015377c0dfe50cc3c1d70a4` (`@astryxdesign/core` **0.6.4**).

The pinned baseline is **771 routes**: 56 non-template routes, the template
index, **659 component block examples across 163 families**, and **55 page
templates**. Every route resolves in this app — ported routes render their
Octane implementation, unported routes render an honest pending placeholder
naming the upstream source. The `/templates/` ledger is the live coverage
inventory.

## Status

Foundation unit (1 of 14) plus later units are landed: app shell,
home/category navigation, coverage inventory, the Button (6) + Text (9)
example slice, the theme runtime, preview shell, overlay and form families. Unit 8 adds 19 image/media block examples and the
media-mode comparison screen.
Unported routes remain honest pending placeholders. See
[docs/coverage.md](docs/coverage.md) for the route/API inventory,
substitutions, findings, and runtime evidence.

## Run

```sh
pnpm install          # from the repo root — links the workspace
pnpm --filter @xplat/astryx-sandbox dev       # vite dev on :5240
pnpm exec turbo run preview --filter=@xplat/astryx-sandbox  # production build + server
# In a second terminal, while preview is running:
pnpm exec turbo run verify:web --filter=@xplat/astryx-sandbox -- --media-only
# Omit --media-only to run the whole maintained Chromium smoke.
```

## Parity comparison (sameframe)

`sameframe.yaml` drives a structured parity matrix against the live site
(`https://astryx.atmeta.com/sandbox/`): home/category/template routes,
three viewports (1440×900, 1024×768, 390×844), the six themes × light/dark,
and interaction states (search results/empty, each category filter, collapsed
rail, nav hover, open theme/mode menus, mobile drawer). With the dev server
on :5240:

```sh
pnpm --filter @xplat/astryx-sandbox sameframe   # writes artifacts/sameframe/
```

Per-page setup lives in `sameframe.setup.mjs`: theme/mode rides upstream's
own `?embed=1&theme=&mode=` contract (also makes the SSR'd reference
client-render, so interactions are deterministic), `sf-pin=1` removes the
post-pin "DiffViewer Perf" card from the reference only (pinned-baseline
normalization pending the section-11 pin decision), and shared
`data-sameframe-key` landmarks keep node matching stable across the port's
different DOM wrapper depth.

This app currently supplies a web host. Actual native-host checks remain separate gates.

## Coverage regeneration

`src/coverage/pinned.ts` is generated by `scripts/generate-coverage.mjs`
against an upstream checkout pinned at `ebd939b…`:

```sh
git -C <astryx-clone> worktree add /tmp/astryx-pin ebd939b665361a078015377c0dfe50cc3c1d70a4
pnpm --filter @xplat/astryx-sandbox coverage -- --astryx /tmp/astryx-pin
```

The generator fails unless the checkout's HEAD is exactly the pinned commit,
and verifies a bijection between the 771 oracle routes and upstream sources.

## Rich content and chat checks

Unit 10 covers 75 pinned Markdown, CodeBlock, syntax-theme, streaming-text and
Chat examples. Run the production preview, then check each browser with text
and DOM assertions only:

```sh
pnpm exec turbo run verify:web --filter=@xplat/astryx-sandbox --concurrency=1 -- --content-chat-only --browser=all
```

The default preview URL is `http://localhost:4173`; `--base=<URL>` selects
another preview. Dictation checks distinguish static states, mocked capability
and callbacks from actual OS speech. See the unit-10 evidence and remaining
host limits in [coverage](docs/coverage.md#unit-10--rich-content-and-chat-examples).

Syntax color data is retained from the pinned Astryx presets: Dracula by Zeno
Rocha, GitHub Light/Dark by GitHub's Primer team, and One Dark Pro by Binaryify
(all MIT). The examples pass these palettes to public CodeBlock overrides.
