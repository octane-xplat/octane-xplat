# Demos

> Finish a small task in your browser, then explore the same source in a native app.

## Goal counter

Complete five steps, undo a step, and reset. A quick introduction to changing screen state.
Preview platform: **web browser**. No account, permission, or network request after loading.
[Try in browser](goal-counter.md) · [Read and run native example](goal-counter.md#run-locally)

## Packing list

Find an item in a bundled day-trip list and mark it packed. Your count includes items hidden by search.
Preview platform: **web browser**. Data stays in this session; nothing is saved to your device.
[Try in browser](packing-list.md) · [Read and run native example](packing-list.md#run-locally)

These previews are browser apps, not simulations of iOS or Android. Each detail page keeps
source and run instructions available even when a preview cannot load. Linux GTK is outside this collection.
