# Package a Linux desktop app

> Use native GTK4 widgets for an experimental Linux desktop app.

Use the experimental native GTK4/GJS runtime. Desktop WebView app hosting and its native-service bridge have been removed. Existing `runtime: "webkitgtk"` configurations must move to native GTK screens or run as browser apps.

Follow [Package a Linux GTK4 app](linux-gtk.md) for setup, packaging, installation, and qualification limits.
